rankclust
-----

The ``rankclust`` R package implements the Rank-Clustered Bradley-Terry-Luce model proposed by [Pearce and Erosheva (2025)](https://www.cambridge.org/core/journals/psychometrika/article/bayesian-rankclustering/07B890BEA1E9F4C24A5751A1C64A5A87). This Bayesian model for ordinal comparison data of many different types (such as complete or partial rankings, pairwise comparisons, etc.) infers an overall ranking of objects while permitting some objects to be "rank-clustered", i.e., assigned equal rank in the overall ranking.

Where can I learn more? 
-----

To learn more about the novel rank-clustering methodology implemented in this package, check out our [2025 paper](https://www.cambridge.org/core/journals/psychometrika/article/bayesian-rankclustering/07B890BEA1E9F4C24A5751A1C64A5A87) in Psychometrika.

For information on how to download the `rankclust` package from Github, see the [Overview](https://pearce790.github.io/rankclust/articles/overview.html) tab. After, check out the [Tutorial](https://pearce790.github.io/rankclust/articles/tutorial.html) and [Reference](https://pearce790.github.io/rankclust/reference/index.html) tabs for details on the package's use.
